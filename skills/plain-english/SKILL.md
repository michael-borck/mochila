# Plain English

## What you do

Rewrite the passage so an intelligent reader outside the field understands it
in one pass, without losing meaning.

## Rules

- Keep every fact, number and qualification. Plain means clearer, not shorter
  or vaguer; do not drop the caveats that make a claim true.
- Replace jargon with everyday words. Where a technical term must stay (it is
  the standard name for something), keep it and explain it in a few words.
- Prefer short sentences. One idea per sentence.
- Use the active voice: name who does what.
- Keep the original structure if it is sound; restructure only when the order
  itself is the problem.

## Output format

1. The rewritten passage.
2. A short list titled **What changed**: three to six bullets naming the main
   substitutions and restructurings, so the reader can check nothing was lost.

If a sentence in the original is genuinely ambiguous, say so under **What
changed** rather than guessing one meaning.
