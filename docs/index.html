mochila — the laptop AI kit

Your AI. Your laptop. No subscription.

mochila is a backpack of free tools that runs AI entirely on your machine: an engine to run models, an agent that reads your files and follows your instructions, and skills written as plain text. An evening to set up. Works on a train, a plane, or with the wifi off.

Nothing you type leaves the machine. There is no account to make, because there is nobody to make one with.

Set it up View source
Runs on modest hardware. A laptop from the last few years handles small models fine; older machines just use smaller models (the setup covers which). macOS, Windows and Linux.

What is in the backpack

Ollama the engine

Runs the model on your machine. One app, one command to pull a model. Everything else sits on top of it.

Pi the agent

A terminal agent with hands: it reads your files, edits them, and runs commands. Works relative to whatever folder you start it in.

Skills plain text

Folders of markdown that teach the agent how you want a job done. No plugin store, no lock-in: the skill travels, the tool can change.

Msty optional GUI

A desktop chat app that finds your local models on its own. For when you want conversations and document folders, not a terminal.

frugal optional cloud

When a task outgrows the laptop, frugal wires in a verified fallback chain of free cloud models.

Portable AI Studio alternative

Want a zero-setup GUI studio instead of a terminal? Portable AI Studio does chat, images and voice in one window, offline. Same engine family, friendlier face, no skills.

Setup: five steps, one evening

  1. Install Ollama. Download from ollama.com, install, start it. Then pull a model (about 5 GB; use qwen3:4b on a smaller machine): 
    ollama pull qwen3:8b
  2. Install Node.js LTS from nodejs.org. Open a new terminal afterwards and check npm --version prints a number.
  3. Connect the agent. One command installs Pi, wires it to your local models, and launches it: 
    ollama launch pi
  4. Add skills. Copy a skill folder from this repo to where agents look for them: 
    mkdir -p ~/.agents/skills
cp -r skills/meeting-notes skills/plain-english ~/.agents/skills/
    Then run /reload inside Pi and check the startup header lists them.
  5. Optional extras. Msty for a desktop chat, or frugal for the free-cloud rung.

Talk to the engine directly, any time:

ollama run qwen3:8b "Say one sentence about this machine."

The ladder

When the subscription is the barrier, there are four places AI can live. Every rung speaks an OpenAI-shaped API, so your tools don't change as you climb — what you learn at the bottom still works at the top:

1 · Local, on your laptop mochila

Ollama + Pi. No keys, no internet, fully private. This page.

2 · Cloud, direct

One provider, one model, your key. Simple, and the cost stays visible.

3 · Cloud, proxied frugal

9Router holds the keys; free-best fails over a verified chain of free models. frugal

4 · Shared, on campus Puente

A server your institution runs for everyone — the full local stack, no setup. locopuente.org

Where your words go

Every AI answer starts with what you type, so it is worth knowing who receives it. There are three kinds of place:

Your machine

Nothing leaves. Not "we anonymise it", not "we don't store it": there is no transmission to have a policy about. This is rung one.

A server someone runs

A campus, a workplace, a lab. Your words sit on their machine, under their rules. Fine when you trust the operator; worth asking what their log policy is.

A cloud provider

Their servers, their retention policy, their jurisdiction. Read it, or assume the worst and act accordingly.

mochila is the option where trust is not required, because there is nothing to trust. Move up the ladder when a task outgrows the laptop — and know exactly what you handed over when you do.
